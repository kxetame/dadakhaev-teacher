# Дадахаев Ибрагим Русланович — учебно-методический сайт

Сайт для студентов и коллег Грозненского государственного колледжа информационных технологий.

## Содержание
- Инженерная графика.
- Инженерная компьютерная графика.
- Учебная практика: ПМ.01 «Оформление и компоновка технической документации».
- Учебная практика: «Подготовка интерфейсной графики». Номер модуля не указан, поскольку он не предоставлен.
- 22 темы: теория, пример, самостоятельные задания, ответы, критерии и интерактивный вопрос.
- Поиск и фильтры, локальный прогресс, печать/PDF и скачивание HTML.
- Методическая памятка для коллег.
- Обратная связь через публичные GitHub Issues с явным подтверждением отправки на GitHub.

## Публикация
Workflow: `.github/workflows/pages.yml`. Публикуется только каталог `public`.
Адрес после успешного развертывания: https://kxetame.github.io/dadakhaev-teacher/
Для работы workflow в Settings → Pages должен быть выбран Source: GitHub Actions.
Проверка проекта: `node scripts/check.mjs`.
Браузерная проверка: `npm install --no-save playwright && npx playwright install chromium && node scripts/browser-check.mjs`.

## Редактирование
Статические страницы находятся в `public/lessons`, главная — `public/index.html`, оформление — `public/styles.css`, интерактивность — `public/app.js`.
`content/lessons.json` хранит содержание и правильные ответы как редакционный справочник; изменение JSON само по себе не перегенерирует HTML. При правке обновляйте соответствующую страницу.
Сторонние зависимости в браузере: необязательный шрифт Google Fonts и счётчик Hits.sh. При их недоступности учебные материалы остаются доступными.

## Фактические границы
Материалы созданы и опубликованы в сентябре 2026 года (первые 12 тем — 14 сентября, ещё 10 тем практики — 15 сентября). Они не являются подтверждением работы сайта в предшествующий учебный год. История коммитов сохраняет реальные даты.
Счётчик Hits.sh отражает обращения к изображению на главной странице, не уникальных посетителей и не официальную подробную аналитику. Повторные запросы и кеширование влияют на показатель; недоступность сервиса не подменяется вымышленным числом.
Для документального подтверждения посещаемости за период потребуется подключить собственный аккаунт аналитики (например, Яндекс Метрика), сохранять отчёты и заверять требуемые материалы у работодателя.
Учебный маршрут не выдаётся за утверждённую рабочую программу. Образование, стаж, награды, результаты студентов и личные контакты не вымышлялись.

## Учебный график 2025–2026
Периоды преподавания предоставлены владельцем сайта: дисциплины — с 12 января по июль 2026; учебные практики — с середины ноября 2025 по июль 2026.
Поле `studyDate` — предложенное распределение темы по учебному графику, а не подтверждение конкретного проведённого занятия. Поле `publishedDate` — фактическая дата первой публикации этой страницы.
По каждой дисциплине сохранено по 3 темы. По каждой практике теперь по 8 тем: 3 существующие и 5 новых. Каталог отсортирован по дате учебного графика; доступен фильтр по месяцу. Существующие отметки прогресса сохраняются, общий объём — 22 темы.
