Электронный архив технического проекта

Подготовьте комплект к передаче: наведите порядок в папках и проверьте его на другом устройстве.

Разберёмся в основе

Электронный архив должен позволять получателю найти нужный документ без пояснений автора. Разделяйте файлы для просмотра, редактируемые исходники и сопроводительную информацию.

Перечень файлов помогает проверить полноту передачи. Укажите название, назначение, формат и версию каждого документа; отдельно сообщите, в какой программе открывается исходник.

Успешное создание ZIP-файла ещё не подтверждает качество комплекта. Архив нужно распаковать в другую папку, сверить состав и открыть основные документы. Не включайте временные файлы и посторонние персональные данные.

Разобранный примерСтруктура учебного архива: папка PDF с чертежом и запиской; папка Source с исходниками; файл README с описанием; перечень файлов. В README указаны обозначение проекта, версия и порядок просмотра.

Порядок работы

  1. Создайте папки для просмотра и исходников.
  2. Сверьте документы с перечнем и уберите временные копии.
  3. Соберите ZIP-архив с понятным именем проекта и версией.
  4. Распакуйте архив отдельно и откройте каждый обязательный файл.

Попробуйте самостоятельно

  1. Базовый: соберите архив своего проекта с PDF, исходником и описанием.
  2. Следующий шаг: передайте архив одногруппнику для проверки открытия файлов.
  3. Запишите найденные замечания и повторите проверку после исправления.
Ответы и ориентир для проверки

Готовый архив должен распаковываться без ошибок; перечень совпадает с содержимым; PDF читаются; исходники присутствуют. Если у получателя нет нужной программы, это указывают отдельно, а документы для просмотра всё равно должны быть доступны.

Критерии выполнения

  • Архив имеет понятное имя и версию.
  • Состав совпадает с перечнем.
  • Проверка выполнена после распаковки.
